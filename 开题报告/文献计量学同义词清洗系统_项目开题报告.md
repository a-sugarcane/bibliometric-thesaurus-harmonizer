# 基于医学主题词知识库的文献计量学同义词自动化清洗与映射系统（Thesaurus Harmonizer）开题报告

**项目名称**：基于医学主题词知识库的文献计量学同义词自动化清洗与映射系统  
**所属领域**：医学信息学 / 科学计量学 / 自然语言处理（NLP）  
**报告日期**：2026-09-20  
**预定研发周期**：3 周

---

## 一、 选题依据与研究背景

### 1.1 研究背景
文献计量学（Bibliometrics）已成为评估全球科学研究前沿演进、学科知识结构与科研合作网络的核心定量分析方法。在临床医学、药理学及跨学科研究领域，文献计量学发文量呈现连年攀升态势。以 VOSviewer、CiteSpace 和 R 语言 Bibliometrix 为代表的可视化分析工具，通过关键词共现网络（Keyword Co-occurrence Network）与聚类分析，直观展示领域核心热点与前沿演进轨迹。

然而，网络图谱分析的可靠性极端依赖于底层输入数据的规范性。在原始数据库（如 Web of Science、Scopus）导出的题录数据中，关键词是由海量作者自由填写的非受控自然语言，存在普遍且严重的表述分歧：
1. **字符串与形态异质性**：单复数（`prostate cancers` vs `prostate cancer`）、连字符有无（`quality-of-life` vs `quality of life`）、大小写及英美拼写差异（`tumor` vs `tumour`）；
2. **缩写与全称分离**：公认专有名词缩写（`ADT`）与全称（`androgen deprivation therapy`）相互孤立；
3. **同义医学术语离散**：同一概念的不同学术表述（如 `cancer of prostate` vs `prostatic neoplasm`）各自成词；
4. **数据破损噪点**：截断错误或连词干扰（如数据中残留的 `logical distress` 脏数据）。

### 1.2 选题目的与应用价值
- **解决高强度手工劳作痛点**：目前全球 90% 以上的文献计量学者仍依赖人工在 Excel 中逐行核对成千上万个关键词并编写 `thesaurus`（同义词表），耗费数天且极易遗漏。
- **解决同行评审信任危机**：国际期刊对文献计量学的方法学审查日益严厉，审稿人频繁针对“关键词未清洗导致图谱节点分裂”或“粗暴合并导致临床前沿细粒度丢失”提出质疑。
- **项目目标**：研发一套集“形态规则清洗 + NLM MeSH 权威受控词表对齐 + 临床概念防滑坡拦截 + 期刊级审计表导出”于一体的自主可控自动化软件系统，实现文献计量数据清洗的标准化、高保真与可复现。

## 二、 国内外研究现状与市场生态评述

### 2.1 传统计量软件的工具链缺失
当前主流文献计量软件（VOSviewer、CiteSpace、Bibliometrix）在系统设计上均采取“只管渲染与聚类、不管上游清洗”的策略。它们普遍提供了同义词替换表的导入接口（如 VOSviewer 的 `thesaurus.txt` 和 CiteSpace 的 `citespace.alias`），但**软件内部完全没有内置自动化生成该文件的算法模块**，将最为繁琐的数据清洗工作完全转嫁给研究者。

### 2.2 通用文本清洗与医学受控词表（MeSH）的应用断层
- **通用文本清洗工具（如 OpenRefine）**：虽然支持基于编辑距离（Levenshtein）和指纹聚类算法，但其缺乏医学本体知识库支持，无法建立医学缩写（如 ADT $\leftrightarrow$ Androgen Deprivation Therapy）的语义链接，且不能直接生成符合文献计量学软件格式的规范产物。
- **专业生物医学 NLP 库（如 scispaCy、QuickUMLS）**：虽然在学术界被广泛用于命名实体识别（NER），但属于底层代码库，缺乏针对文献计量学“共现矩阵去重、篇级二值计数（Binary Counting）、格式转换”的专用工程封装。

### 2.3 AI Agent 与开源社区现状（GitHub & Skill-Hub 调研）
经检索 GitHub 开源生态与新兴的 AI Agent Skill 知识库（如 Skill-Hub）：
- 现有学术类工具主要集中在文献检索（如 `openalex-skill`）、选刊推荐（`journal-fit-finder`）或泛化论文写作上。
- 关于文献计量学关键词同义清洗的公开成果，仅见于少数论文配套仓库中零散、针对特定数据集硬编码的简单 Python 脚本（30~50 行 `pandas.replace`），**全球开源社区尚无一款开箱即用、具有三级置信度防护与审稿证据链闭环的同构系统**。

## 三、 研究目标、研究内容与关键科学问题

### 3.1 研究目标
1. 构建完全自主可控、跨平台的轻量级文献计量学同义词自动化清洗系统（Thesaurus Harmonizer）。
2. 本地化封装包含 3 万余条标准主题词及 30 万条入口词的 NLM MeSH 离线语义倒排索引库（~15MB）。
3. 建立三级置信度仲裁体系与临床概念防滑坡硬拦截系统，杜绝过度合并。
4. 提供基于 Streamlit 的现代化交互界面，一键导出全套软件适配文件及审稿人核查报告。
5. 产出符合国家版权局形式审查标准的自主原创代码，申报国家计算机软件著作权。

### 3.2 主要研究内容

1. **多源异构题录自适应解析算法**：实现对 Web of Science (WoS) 纯文本及 VOSviewer 导出文件的原生无损解析，执行单篇文献级别的二值去重（Binary Deduplication），杜绝合并后的频次虚假虚高。
2. **基于上下文感知的形态学清洗引擎**：基于 `inflect` 与 `spaCy`，实现仅对多词名词短语末尾中心词的精准单复数还原，并设立生物医学专科后缀白名单（如 `-omics`、`distress`），彻底解决传统 Stemmer 算法破坏专有名词词根的缺陷。
3. **轻量离线 MeSH 语义对齐机制**：解析 NLM 官方 XML 数据源，建立全小写入口词倒排哈希字典，保证在单机离线环境下实现毫秒级查表，彻底规避在线爬虫的封 IP 与延迟问题。
4. **基于语义集合差异的临床防滑坡拦截机制**：针对肿瘤分期（`mCRPC`、`metastatic`）与精神心理诊断（`MDD` vs `distress`）等设立硬拦截正则集，防止前沿微观演化被宏观大词吞噬。
5. **四级规范词仲裁协议（Arbitration Protocol）**：解决“两个合法同义词谁并入谁”的逻辑困境，确立“缩写向全称靠拢、冷僻词向本地数据集高频临床惯例靠拢”的科学裁决标准。

### 3.3 拟解决的关键科学与技术问题
- **关键问题 1：如何平衡“同义词规范归一”与“前沿演进分辨率保留”之间的内在矛盾？**  
  *解决思路*：提出“高危限定词集合差分检测算法”，当两词的差异集合属于保留词缀时，强制拦截并提升预警等级，由学者介入复核。
- **关键问题 2：如何在单机零网络依赖环境下实现大规模医学受控词的极速对齐？**  
  *解决思路*：采用基于哈希表的轻量级 JSON/SQLite 倒排索引技术，将 30 万条医学概念关系压缩至 15MB 内存空间，实现 $O(1)$ 复杂度的瞬时检索。

## 四、 项目特色与创新点

1. **首创“受控词典（MeSH）+ 临床高频惯例”的双轨规范词判定模型**：
   彻底打破传统数据清洗中“要么全凭主观语感、要么死板遵从冷僻医学词”的弊端。既利用国际权威词表判定概念等价性，又依据真实文献集词频保留学术界通用表达（例如将 `prostatic neoplasms` 智能归一为临床主流的 `prostate cancer`）。
2. **首创文献计量学“防概念滑坡（Anti-Concept-Slippage）”防御体系**：
   首次将肿瘤分期学、精神诊断学标准固化为清洗软件的底层防火墙，从算法层面阻断了“耐药分期被泛癌吞噬”、“心理症状与器质疾病混淆”的方法学硬伤，大幅提高计量论文的同行评审通过率。
3. **开创“清洗-映射-证据链存证”三位一体的论文合规闭环**：
   软件不仅输出绘图工具所需的控制文件，还同步生成排版规范的《同义词清洗与规范化审计表（Supplementary Table）》，直接交代每个词的合并依据、知识库来源与安全校验状态，彻底终结审稿人对“清洗黑箱”的质疑。
