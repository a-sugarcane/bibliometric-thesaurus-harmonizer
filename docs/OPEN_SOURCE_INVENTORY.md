# 开源项目选型、调用与生命周期跟踪清单 (Open Source Inventory)

> **工程原则**：
> 1. **能调用成熟开源项目就先调用开源项目**，坚决不重复造轮子；
> 2. **轻量化与零网络依赖优先**，确保系统在单机离线环境下 100% 稳定运行；
> 3. **合规性硬约束**：仅采纳 MIT、Apache 2.0、BSD 等宽松商业友好协议，严禁强传染性 GPL 协议；
> 4. **动态生命周期跟踪**：如实记录所有评估的开源组件；若经测试论证确认不采用某项目，必须以~~删除线~~标明并写明客观技术驳回依据，严禁随意删除历史决策轨迹。

## 一、 开源项目选型与决策矩阵

| 业务领域与功能模块 | 候选开源项目 | 决策状态 | 开源协议 | 核心用途 / 裁决理由与考量 |
| :--- | :--- | :---: | :---: | :--- |
| **形态学中心词还原** | `inflect` | **[已采用]** | MIT | 用于英文复合短语末位核心名词的单数转换（Singularization）。体积小、确定性高，无需庞大语料库。 |
| **通用 NLP 与词元还原** | `spacy` | **[已采用]** | MIT | 作为 `inflect` 的工业级后备降级引擎。 |
| **通用 NLP 与词元还原** | ~~`nltk` (WordNetLemmatizer)~~ | **[已确认弃用]** | Apache 2.0 | **弃用理由**：首次运行强制联网下载庞大数据包（如 `punkt`, `wordnet`），离线环境极易崩溃；对医学希腊/拉丁词缀（如 `-ses` $\to$ `-sis`）规则泛化能力差。 |
| **医学本体数据流解析** | `xml.etree.ElementTree` + `gzip` | **[已采用]** | Python PSF | Python 官方原生流式迭代解析器（`iterparse`）。零额外依赖，直接读取 `.gz` 压缩流，单机内存消耗稳定在 50MB 以内，3.3 秒内完成 380MB MeSH 数据的解析与倒排索引构建。 |
| **医学本体与 MeSH 工具** | ~~`pymesh`~~ | **[已确认弃用]** | AGPL / MIT | **弃用理由（严重命名碰撞）**：PyPI 上的 `pymesh` 实为“3D 几何三角网格（Polygon Mesh）处理库”，与美国国家医学图书馆（NLM MeSH）完全同名但毫无关联。 |
| **医学本体与 MeSH 工具** | ~~`QuickUMLS`~~ | **[已确认弃用]** | MIT | **弃用理由**：强依赖 UMLS 完整元知识库安装（解压需 50GB 磁盘），且需要申请 UMLS 专有研究许可与 API Key，严重违背轻量化、离线化系统定位。 |
| **PubMed 检索与数据流** | `biopython` (`Bio.Medline`) | **[评估备选]** | Biopython | 具备成熟的 MEDLINE 格式解析。目前系统已自研轻量原生 `pubmed_parser.py`（支持副题词与星号剥离），后续若扩展 PubMed API 在线检索时可引入。 |
| **计量网络与题录分析** | ~~`metaknowledge`~~ | **[已确认弃用]** | GPL-3.0 | **弃用理由**：采用强传染性 GPL-3.0 协议，阻碍软著申报与宽松商业化开源；且捆绑了庞大的 `networkx`、`scipy`、`matplotlib`，而本项目核心是关键词清洗与同义词生成，而非网络绘图。 |
| **Scopus 数据库对接** | ~~`pybibliometrics`~~ | **[已确认弃用]** | MIT | **弃用理由**：专用于调用 Elsevier 官方 REST API，强依赖 Scopus API 密钥和机构 IP 白名单，不适合解析用户直接从 Scopus 网页端导出的离线 CSV/RIS 文件。 |
| **表格数据与二值去重** | `pandas` | **[已采用]** | BSD-3 | 用于 Scopus CSV 处理、词频统计矩阵及前端数据表格转换。 |
| **审稿人核查表导出** | `openpyxl` | **[已采用]** | MIT | 用于高保真生成符合期刊补充材料规范的 `Thesaurus_Audit_Report.xlsx`。 |
| **交互式 Web 仪表盘** | `streamlit` | **[已采用]** | Apache 2.0 | 提供轻量响应式 Web 界面，内置 `st.data_editor` 支持研究者在网页端直接交互审核、微调三级置信度表格。 |
| **自动化测试框架** | `pytest` / `unittest` | **[已采用]** | MIT / PSF | 提供自动化测试与持续集成保障。 |

## 二、 后续评估计划

1. **中文分词与医学词表（CNKI 模块增强）**：
   - 候选项目：`jieba`（MIT）或 `pkuseg`（临床医学微调模型）。
   - 评估目标：针对知网导出词中未用分号规范切分的连贯短语执行安全分词。
2. **文本相似度算法评估**：
   - 候选项目：`rapidfuzz`（MIT，C++ 加速 Levenshtein / Jaro-Winkler）vs 原生差分算法。
   - 评估目标：在不破坏临床分期硬拦截的前提下，为非 MeSH 收录的长尾拼写变体提供编辑距离建议。
